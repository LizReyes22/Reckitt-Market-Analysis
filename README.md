# Reckitt-Market

Proyecto de análisis de mercado desarrollado en **Excel**, orientado a la organización, limpieza y visualización de información comercial.

## 🛠️ Herramientas
- Microsoft Excel (tablas dinámicas, fórmulas de búsqueda, condicionales, cálculos comerciales, cambios de formato & gráficos)

## 📂 Contenido
- `Reckitt-Market.xlsx` → Archivo principal con el análisis completo


## 📊 Resultados
- Identificación de Unidades Vendidas en 2022 & 2023 
- Promedio de ventas por unidad
- Tasa de crecimiento de ventas
